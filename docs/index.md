# tack

tack is a full-featured user-focused pinning system for nix inputs.

it provides:
- declarative inputs from any nix-compatible source
- easy and convenient management of updates and rollbacks
- mechanisms for following branches, tags, and fixed inputs
- automated patch following
- input grouping
- user-defined shorturls (`myforge:someuser/somerepo`)
- commit signing verification

and much, much more.

to get started, let's look at [obtaining](obtaining.md) tack itself.
